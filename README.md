# Oshkon

MVP гостевой версии сервиса бронирования столиков.

## Запуск

```bash
npm install
npx prisma db push
npx prisma db seed
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Тестовый аккаунт: `test@test.com` / `password`.

В интерфейсе реализован путь: выбор ресторана → выбор столика на схеме зала → предзаказ → демо-оплата → просмотр и отмена брони. Для мгновенного локального сценария состояние интерфейса сохраняется в `localStorage`; схема Prisma и seed создают такую же базу SQLite для подключения серверных маршрутов.
